# Security Policy

If you find a security vulnerability in a BeamWarpRift project, please report it privately:
open the project on GitHub, go to **Security → Report a vulnerability**, and describe it there.
Please do not open a public issue for security problems.

A useful report includes the affected product and version, the steps to reproduce, and what an attacker could do.

Reports are read by the developer, Lionrick333. Fixes ship in a new release; the latest release is the supported one.
